## Важно про ветки

Документы находятся в ветке `lab5`, где собраны все лабораторные. При этом:

* в ветке `lab4` первый микросервис работает на **SQLite**;
* в ветке `lab5` тот же сервис переведён на **PostgreSQL** для общей БД;
* подробности различий описаны в `lab4/docs/РАЗБОР.md` и
  `lab5/docs/РАЗБОР.md`.

## Как готовиться к защите

1. Прочитать разбор соответствующей лабораторной.
2. Открыть перечисленные файлы и найти в них названные классы/методы.
3. Пройти чек-лист демонстрации на запущенном приложении.
4. Проговорить ответы на вероятные вопросы из последнего раздела.
5. Для каждой лабы уметь назвать: точку входа, главный класс/контроллер,
   способ связи компонентов и способ хранения данных.
